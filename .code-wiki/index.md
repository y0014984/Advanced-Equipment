# code wiki

Agent-maintained project notes for Advanced Equipment. The code is the source of truth; this wiki layer stores decisions, rationale, gotchas, and current-behavior summaries that the code cannot express on its own.

The public mod documentation starts at [wiki/Home.md](../wiki/Home.md). This index is for maintenance topics used by agents and contributors.

## how to use

- Agents: load a topic file when a task touches code paths it describes.
- Humans: each topic should be a short read with links to the relevant code and public docs.
- Keep one topic per file.
- Keep topic files under roughly 500 lines.
- Re-check claims against code before editing a topic.
